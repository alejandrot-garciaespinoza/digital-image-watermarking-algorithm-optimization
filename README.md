# Optimization with Metaheuristics of the Parameters of a Digital Image Watermarking Algorithm based on DWT and SVD

by Alejandro Tonatiuh García Espinoza, Maya Carrillo Ruiz, Rogelio González Velázquez, Juan Fransisco Leyva Bonilla.

# Environment Setup
First, clone this repository: 
`git clone https://github.com/alejandrot-garciaespinoza/digital-image-watermarking-algorithm-optimization.git`

Next, navigate to the code directory:
` cd digital-image-watermarking-algorithm-optimization `.

Finally, create a virtual environment using venv or your preferred tool and install dependencies:
```shell
python -m venv /path/to/new/virtual/environment # Replace this with the appropiate command for you preferred tool
pip install -r requirements.txt
```
